# Cursor Templates

This directory contains copyable Cursor rules, commands, and subagent cards from the author's current working setup.

## Suggested Layout

Copy the files into a project as:

```text
.cursor/
  agents/
    Junior SWE.md
    Middle SWE.md
    Senior SWE.md
    Lead QA.md
    Verifier.md
    Verifier Pro.md
  commands/
    Techlead.md
  rules/
    Techlead.mdc
```

The subagent cards include the Compass rules inline, so a separate `SubagentRules.md` file is not required.
