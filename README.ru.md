## Обзор

Agent Compass — это не просто prompt для AI-ассистента. Это **policy framework** для разработки с AI: набор правил, который превращает ассистента из непредсказуемого генератора кода в дисциплинированного разработчика с понятными ролями, отчётностью, правилами безопасности, требованиями к верификации и рабочими контрактами для проекта.

Версия 2 расширяет исходную идею:

- `COMPASS.md` остаётся компактным англоязычным набором User Rules для Cursor.
- `AGENTS.md` описывается как операционный контракт конкретного репозитория.
- `TODO.md` рассматривается как живой технический roadmap, а не как плоский чеклист.
- Субагенты описываются как управляемая команда исполнителей, верификаторов и QA-эскалации под управлением Senior AI / техлида.

> Русская документация является авторским source of truth для v2-практик. Главный `README.md` остаётся английским публичным entrypoint репозитория.

## С чего начать

### Установка в Cursor IDE

1. Откройте Cursor IDE.
2. Нажмите `Ctrl+Shift+P` (`Cmd+Shift+P` на macOS).
3. Найдите команду `View User Rules`.
4. Скопируйте содержимое [`COMPASS.md`](./COMPASS.md) в User Rules.
5. Сохраните настройки и начните новый чат.

`COMPASS.md` намеренно оставлен на английском языке: он короче, стабильнее для LLM и лучше работает как компактный набор универсальных правил. Если нужно адаптировать роль, язык отчёта или платформу, меняйте только соответствующие строки под свой workflow.

## Ключевые идеи

### Роли: Архитектор и Разработчик

Пользователь остаётся Software Architect: задаёт направление, принимает архитектурные решения и утверждает спорные trade-off. AI работает как Developer: выполняет задачи, оценивает риски, объясняет значимые отклонения и не скрывает незавершённую работу.

### Отчёт по форме

Ответ AI завершается структурированным отчётом:

- **Changes Made:** что изменено.
- **UX:** как пользователь должен ощутить изменения, если это применимо.
- **Unfulfilled Tasks:** что не удалось завершить.
- **Manual Changes Required:** что требует ручного вмешательства.
- **Special Attention Required:** что нужно особенно проверить.
- **Rationale for significant deviations:** почему выбран нетипичный путь.

Фраза `отчёт по форме` намеренно остаётся полезным якорем: на практике LLM строже соблюдает формат, когда эта команда заметно отличается от остального текста.

### `AGENTS.md` как операционный контракт

`README.md` объясняет проект человеку. `AGENTS.md` должен объяснять агенту, как безопасно работать в конкретном репозитории:

- какие документы читать первыми;
- где находится основной код;
- какие зоны нельзя трогать;
- какая команда локальной CI обязательна перед финальным отчётом;
- какие термины и проектные инварианты нельзя потерять.

Подробная схема вынесена в [`docs/ru/AGENTS.md`](./docs/ru/AGENTS.md). Логически это место является source of truth для практики `AGENTS.md`; проектные blueprint-документы вроде Agent Enforcer 2 могут ссылаться сюда и добавлять только свои CI-специфичные детали.

### `TODO.md` как живой технический документ

В Agent Compass `TODO.md` — это не список "когда-нибудь сделать". Это рабочий документ между человеком и агентами:

- roadmap фаз или тематических волн;
- лог решений и статусов;
- контейнер для критериев завершения;
- источник контекста для техлида и субагентов.

Подробный формат описан в [`docs/ru/TODO.md`](./docs/ru/TODO.md).

### Субагенты и режим техлида

Для сложных задач Senior AI может работать как техлид: кластеризовать задачи, делегировать исполнителям, запускать верификаторов после каждого кластера и эскалировать сложные проблемы на QA-агентов.

Актуальная практика основана на стандартном наборе разработки и правилах техлида из авторского Cursor setup: `Junior SWE`, `Middle SWE`, `Senior SWE`, `Verifier`, `Verifier Pro` и `Lead QA`. Базовые правила Compass встроены прямо в карточки субагентов, чтобы они работали без отдельного bootstrap-файла.

Подробный workflow описан в [`docs/ru/SUBAGENTS.md`](./docs/ru/SUBAGENTS.md).
Копируемые карточки и правила техлида лежат в [`templates/cursor.ru/`](./templates/cursor.ru/).

## Часть экосистемы Artemonim's Agent Tools

Agent Compass входит в экосистему [Artemonim's Agent Tools](https://github.com/Artemonim/AgentTools):

- [Agent Enforcer 2](https://github.com/Artemonim/AgentEnforcer2) — blueprint локальной CI и reference architecture.
- Agent Viewport — концепт понимания UI-разметки AI-ассистентами, сейчас on hold.

## Кому это полезно

- Пользователям Cursor IDE, которые хотят стабильного качества AI-generated code.
- Архитекторам, делегирующим реализацию AI-агенту.
- Командам, которые хотят единые правила AI-assisted разработки.
- Разработчикам, которым нужен воспроизводимый агентный workflow с локальной CI и верификацией.
